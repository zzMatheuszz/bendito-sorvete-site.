# Bendito Sorvete | Site

Site da Bendito Sorvete, sorveteria de Arapongas-PR com sorvetes sem adição de açúcar.

- `index.html`: página única (Tailwind via CDN)
- `imagens/`: fotos da loja e dos produtos
- `imagens/galeria/`: fotos da vitrine que roda na horizontal (640x800)

Para trocar uma foto, substitua o arquivo mantendo o mesmo nome.
